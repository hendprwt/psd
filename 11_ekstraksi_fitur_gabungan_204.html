10. Ekstraksi Fitur Gabungan (204 Fitur) — Pendekatan Linier & Polynomial#

Notebook ini menghasilkan dua file CSV berisi 204 fitur gabungan dari tiga polutan (NO2, CO, SO2) yang diekstraksi menggunakan 68 fungsi TSFEL. Perbedaan antara dua file terletak pada metode imputasi missing value yang dipakai:

File Keluaran

Metode Imputasi

Keterangan

fitur_all_linear_bundah_sreseh.csv

Interpolasi Linier (time-based)

Metode yang digunakan pada Tugas 5 & 6

fitur_all_polynomial_bundah_sreseh.csv

Interpolasi Polynomial (orde 2, kuadratik)

Pendekatan alternatif yang menangkap kurva lengkung antartitik

Adapun preprocessing yang diterapkan sebelum ekstraksi fitur sama untuk keduanya: deteksi dan penghapusan outlier dengan metode IQR, diikuti imputasi missing value dengan metode yang berbeda, kemudian ekstraksi 68 fitur TSFEL.

Format output: 1 baris × 204 kolom. Setiap kolom diberi awalan nama polutan, misalnya NO2_abs_energy, CO_spectral_entropy, SO2_kurtosis, dst.

1. Persiapan Pustaka dan Konfigurasi#

2. Fungsi Bantu#

Dua fungsi disiapkan:

  • to_scalar(): memastikan hasil TSFEL yang berupa list/array dikembalikan sebagai satu nilai numerik (rata-rata), kompatibel dengan fitur multi-nilai seperti mfcc, lpcc, ecdf_percentile.

  • extract_one(): memanggil satu fungsi TSFEL berdasarkan namanya secara dinamis, mendeteksi otomatis apakah fungsi tersebut memerlukan parameter fs atau tidak.

def to_scalar(result):
    """Konversi hasil TSFEL (scalar/list/dict) ke satu nilai float."""
    if isinstance(result, dict) and 'values' in result:
        result = result['values']
    if isinstance(result, (list, tuple, np.ndarray)):
        arr = np.asarray(result, dtype=float)
        return float(np.nanmean(arr))
    return float(result)


def extract_one(fn_name, signal, fs):
    """Panggil fungsi TSFEL berdasarkan nama string, dengan/tanpa parameter fs."""
    fn = getattr(tsfel_features, fn_name)
    params = inspect.signature(fn).parameters
    result = fn(signal, fs) if 'fs' in params else fn(signal)
    return to_scalar(result)


def clean_and_extract(df_raw, col, prefix, interp_method='linear', poly_order=2):
    """
    Preprocessing + ekstraksi 68 fitur TSFEL untuk satu polutan.

    Parameters
    ----------
    df_raw        : DataFrame dengan kolom 'date' dan 'col'
    col           : nama kolom polutan (str)
    prefix        : awalan nama fitur keluaran, mis. 'NO2'
    interp_method : 'time' untuk linier berbasis waktu,
                    'polynomial' untuk kuadratik (perlu poly_order)
    poly_order    : orde polynomial (digunakan saat method='polynomial')

    Returns
    -------
    dict {prefix_fnname: nilai}
    """
    df = df_raw[['date', col]].copy()
    df[col] = pd.to_numeric(df[col], errors='coerce')

    n_before = df[col].isna().sum()

    # Hapus outlier dengan IQR
    Q1, Q3 = df[col].quantile(0.25), df[col].quantile(0.75)
    IQR = Q3 - Q1
    lb, ub = Q1 - 1.5 * IQR, Q3 + 1.5 * IQR
    n_outlier = ((df[col] < lb) | (df[col] > ub)).sum()
    df.loc[(df[col] < lb) | (df[col] > ub), col] = np.nan

    n_total_nan = df[col].isna().sum()

    # Imputasi sesuai metode yang dipilih
    df_idx = df.set_index('date')
    if interp_method == 'polynomial':
        df_idx[col] = df_idx[col].interpolate(method='polynomial', order=poly_order)
    else:
        df_idx[col] = df_idx[col].interpolate(method='time')
    df_idx[col] = df_idx[col].ffill().bfill()

    n_after = df_idx[col].isna().sum()
    signal = df_idx[col].astype(float).values

    print(f"  {prefix}: NaN awal={n_before}, outlier IQR={n_outlier}, "
          f"total NaN sebelum imputasi={n_total_nan}, sisa setelah imputasi={n_after}")
    print(f"  IQR bounds: [{lb:.6f}, {ub:.6f}]")

    # Ekstraksi 68 fitur
    row = {}
    for fn_name in FEATURE_LIST:
        row[f"{prefix}_{fn_name}"] = extract_one(fn_name, signal, fs)
    return row

4. Ekstraksi Fitur — Imputasi Linier (Time-based)#

Pada pendekatan linier, nilai NaN diisi dengan interpolasi berbasis waktu (method='time') yang mengasumsikan perubahan nilai berjalan secara linier dan proporsional antara dua titik data valid yang mengapitnya. Ini adalah metode yang sama dengan yang digunakan pada Tugas 5 dan 6.

print('=== IMPUTASI LINIER ===\n')
combined_linear = {}
for col, prefix in POLLUTANTS.items():
    print(f'--- {prefix} ---')
    row = clean_and_extract(df_main, col, prefix, interp_method='time')
    combined_linear.update(row)
    print()

5. Ekstraksi Fitur — Imputasi Polynomial (Kuadratik, Orde 2)#

Pada pendekatan polynomial, nilai NaN diisi dengan interpolasi kuadratik (order=2) yang menyesuaikan kurva orde-2 melalui titik-titik data di sekitar celah kosong. Pendekatan ini lebih fleksibel dari interpolasi linier:

  • Lebih akurat di segmen data yang tren-nya melengkung (percepatan/perlambatan polutan musiman).

  • Bisa menghasilkan nilai sedikit berbeda di luar rentang yang linier tidak mampu menangkap.

Kedua file akhir kemudian dapat digunakan sebagai bahan perbandingan dalam analisis apakah metode imputasi berpengaruh terhadap kualitas fitur dan hasil clustering.

6. Perbandingan Hasil Kedua Pendekatan#

Untuk mengecek perbedaan nilai fitur yang dihasilkan oleh kedua metode imputasi, dihitung selisih absolut rata-rata dan selisih maksimum per fitur. Fitur yang nilainya sangat berbeda antar-metode adalah yang paling sensitif terhadap cara kita mengisi celah data.

diff = (df_linear - df_poly).abs()
summary = pd.DataFrame({
    'Max_Abs_Diff': diff.max(),
    'Mean_Abs_Diff': diff.mean(),
    'Pct_Diff (%)': (diff / df_linear.abs().replace(0, np.nan) * 100).max()
})
